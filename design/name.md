# Tessryn

Tessryn is pronounced **TESS-rin**. The name suggests tessellation: independent pieces joining into a coherent whole. It fits the project’s aim of making servers and qualified laptops cooperate as a distributed inference system, while remaining broad enough for a complete operating system.

The name is an invented project name, rather than an acronym. Use **Tessryn** in prose and `tessryn` for repository names, commands, and identifiers.
